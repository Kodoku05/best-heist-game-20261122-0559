GILDED: The Star Sapphire Gala Heist — a top-down heist game. You are Marlowe Fox, gentleman thief, working a museum gala across four floors: mingle with the guests as living cover, read guard vision cones and sweeping cameras, time the laser grids, pick the vault, hack the cameras dark, and lift the Star Sapphire before the alarm meter hits lockdown. Loot is heavy — every kilo slows you down — so the getaway is a choice, not a given. Ghost a floor for three stars. Every pixel is drawn in code; every sound is synthesized.

## Run it

```sh
node serve.ts
```

Open localhost:8080. WASD or arrows move, Shift sprints (fast, loud), C sneaks, click throws a coin toward the cursor, Q drops smoke, F fires an EMP, E picks locks and hacks terminals, P pauses, R restarts, M mutes. Grab the Star Sapphire, then reach the green EXIT. A ghost bot proves every floor winnable unseen: open `?selftest=1`.
